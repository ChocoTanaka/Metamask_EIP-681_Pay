# MetaMask JPYC Sub-Payment System
## About

This app is a payment support app using MetaMask.

Import accounts from MetaMask and create invoices compliant with ERC-681.

The developer does not obtain any personal information through this app.

## Manual

[This link](https://github.com/ChocoTanaka/Metamask_EIP-681_Pay/blob/master/Sub-Payment_Manual.pdf)

## We can use

- MetaMask
- HashPort Wallet
- Uniswap Wallet
- Rabby wallet

- After checking, Bitget, Base, and OKX Wallet are not recommended 
because they are behaving abnormally.

- Trust is also available, but not recommend

ERC-681 QR codes can be scanned using various wallets.
